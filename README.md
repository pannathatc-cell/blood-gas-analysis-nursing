# ABG NSSKRU

เว็บแอปแปลผลก๊าซในเลือดแดง (ABG) เชื่อมโยงการพยาบาล และเกมฝึก GBL สำหรับนักศึกษาพยาบาล
คณะพยาบาลศาสตร์ มหาวิทยาลัยราชภัฏศรีสะเกษ

ผลการเล่นและการเข้าใช้งานของนักศึกษาบันทึกลง Google Sheet
`1bV3ToecEFKpfnIgWJASQaVAMfgItPQ0hB_uPvSCUJnQ`

## ไฟล์ในโฟลเดอร์นี้

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `index.html` | ตัวเว็บแอปทั้งหมด (ภาพการ์ตูนฝังอยู่ในไฟล์แล้ว) |
| `favicon.png` | ไอคอนแท็บ (ตราคณะ) |
| `.nojekyll` | ให้ GitHub Pages ส่งไฟล์ตามเดิม |
| `apps-script/Code.gs` | โค้ด Google Apps Script ที่รับข้อมูลลง Sheet (ไม่ต้องอัปขึ้น GitHub) |

## ขั้นที่ 1 — ตั้งค่า Google Sheet (ทำครั้งเดียว)

1. เปิด Google Sheet → เมนู **ส่วนขยาย → Apps Script**
2. ลบโค้ดเดิม วางโค้ดทั้งหมดจาก `Code.gs` → กดบันทึก
3. ที่แถบด้านบน เลือกฟังก์ชัน **setup** → กด **เรียกใช้** → อนุญาตสิทธิ์
   ระบบจะสร้างแท็บ **Results** และ **Visits** พร้อมหัวตาราง
4. กด **ทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่**
   - ประเภท: **เว็บแอป**
   - เรียกใช้ในฐานะ: **ฉัน**
   - ผู้ที่มีสิทธิ์เข้าถึง: **ทุกคน**
5. คัดลอก **URL ของเว็บแอป** (ลงท้ายด้วย `/exec`)

## ขั้นที่ 2 — ใส่ URL ลงในแอป

เปิด `index.html` ค้นหาคำว่า `PASTE_APPS_SCRIPT_WEB_APP_URL_HERE` แล้ววาง URL แทน

```js
const SHEET_API = "https://script.google.com/macros/s/xxxxxxxx/exec";
```

## ขั้นที่ 3 — อัปขึ้น GitHub Pages

1. สร้าง repository ใหม่บน GitHub (เช่น `abg-nsskru`) แบบ Public
2. อัปโหลด `index.html`, `favicon.png`, `.nojekyll`
3. ไปที่ **Settings → Pages** → Source: **Deploy from a branch** → Branch: `main` / `(root)` → Save
4. รอ 1–2 นาที จะได้ลิงก์ `https://<ชื่อบัญชี>.github.io/abg-nsskru/`

## การใช้งาน

- **นักศึกษา:** เปิดลิงก์ ใส่ชื่อเล่น แล้วเล่น ผลทุกรอบส่งเข้า Sheet อัตโนมัติ
  ถ้าเน็ตหลุด ผลจะเก็บไว้ในเครื่องและส่งให้เองเมื่อเชื่อมต่อได้
- **อาจารย์ (แอดมิน):** พิมพ์รหัสแอดมินในช่องชื่อเล่น จะเห็นแท็บแดชบอร์ดชั้นเรียนและสถิติการเข้าใช้งาน
  ข้อมูลดึงจาก Sheet ใหม่ทุก 30 วินาที
- นักศึกษาส่งข้อมูลเข้า Sheet ได้อย่างเดียว อ่านข้อมูลกลับต้องใช้รหัสแอดมิน

## เปลี่ยนรหัสแอดมิน

ต้องแก้ 2 ที่ให้ตรงกัน
1. `Code.gs` → `ADMIN_KEY` แล้ว **ทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้ → แก้ไข → เวอร์ชันใหม่**
2. `index.html` → `ADMIN_HASH` (ค่า SHA-256 ของรหัสใหม่)

## แก้โค้ด Apps Script ภายหลัง

ทุกครั้งที่แก้ `Code.gs` ต้องกด **จัดการการทำให้ใช้งานได้ → แก้ไข (ไอคอนดินสอ) → เวอร์ชัน: ใหม่ → ทำให้ใช้งานได้**
URL `/exec` จะคงเดิม ไม่ต้องแก้ใน `index.html`
